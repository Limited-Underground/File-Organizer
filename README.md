Confirmed baseline: C#, .NET 10, SQLite, offline core operation. Avalonia is the preferred UI, subject to technical evaluation.

Development requires .NET SDK 10.0.303 and PowerShell 7.2+. Run `./tools/Test-Development.ps1` for locked restore, Debug/Release builds and tests. Launch `dotnet run --project src/FileOrganizer.Desktop` for the shell. Normal application state uses the per-user LocalApplicationData convention; developer smoke runs require the marked disposable fixture described in [project status](docs/PROJECT_STATUS.md). Closing the window stops the in-process worker. No folders are scanned.

The Windows-only test harness creates small, owned fixtures beneath ignored `artifacts/FO-003-fixtures-20261029/fixtures/`, retains manifests and receipts, and has no cleanup API. It exercises deterministic throw/cancel checkpoints without running the large benchmark or production recovery scenarios in the [benchmark plan](docs/BENCHMARKS.md).

Choose **Inventory** to read saved catalogues and 50-row pages. Refresh selects current saved publication; Previous/Next remain pinned to one generation and warn if publication changes. A known catalogue with only unfinished attempts shows status without staging rows. The view explicitly reports non-atomic observations and unknown live-drive availability. Cancel, navigation and shutdown invalidate stale completions; shutdown joins every outstanding read before releasing the profile lease. Fresh schema-1 profiles show no saved inventory; opening this view does not create or migrate an inventory database or start indexing.

Choose Name or root-relative Path, enter up to 128 UTF-16 code units and choose All/File/Folder/Excluded-link kind, then **Apply** or press **Enter**; **Clear** resets the applied filter. Typing alone runs no query. Matching is literal fixed ordinal case-insensitive substring search: `%`, `_`, quotes and whitespace are literal, with no automatic Unicode normalization or volume case detection. The applied summary is separate from draft controls; counts describe the saved catalogue total, not a filtered-total count. Cursor history resets when filters change. Active-filter evaluation has cancellation and typed time/work limits; it does not promise a universal five-second query or shutdown deadline.
